## ✨ Features
- 🔄 **Automated Roster Generation**: Instantly create monthly or quarterly rosters via Python.
-  **Holiday Integration**: Pre-configured with annual public holiday calendars to ensure compliance.
- 👥 **Role-Based Scheduling**: Supports SOC L1, L2, L3 Team Leads, SIEM Engineers, Firewall Operations, and dedicated Backups.
- 🛡️ **24/7 Coverage Validation**: Automated checks to ensure zero gaps in SOC monitoring across all shifts.
-  **Statistical Analysis**: Automatic calculation of total work days, shift counts (Morning/Afternoon/Night), week-offs, and holiday coverage.
- 🏥 **Health & Wellness Module**: Dedicated guidelines and tracking to prevent burnout in rotational shift workers.
- 🎨 **Professional Formatting**: Generates color-coded Excel outputs with merged cells, borders, and clear visual indicators.

## 📖 Project Overview
Managing a 24/7 SOC requires balancing continuous security monitoring with analyst well-being. ShiftGuard addresses the core challenges of:
- Managing complex rotational shifts across multiple team members without coverage gaps.
- Ensuring compliance with labor regulations and continuous operational readiness.
- Maintaining team health, work-life balance, and preventing alert fatigue.
- Tracking public holidays, planned leaves, and special observances seamlessly.
